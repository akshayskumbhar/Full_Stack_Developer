jQuery UI Tabs

The Tabs widget divides content into multiple panels, allowing users to switch between sections easily.

1️⃣ Basic Tabs

This is the default tabs behavior. Click on the tab headers to switch content.

$("#tabs1").tabs();

2️⃣ Set Active Tab

Using active, you can define which tab opens by default. Index starts from 0.

$("#tabs2").tabs({ active: 1 });

3️⃣ Collapsible Tabs

With collapsible: true, the active tab can be closed.

$("#tabs3").tabs({ collapsible: true });

4️⃣ Programmatic Tab Control

Tabs can be controlled using buttons and methods.

$("#tabs4").tabs(); $("#openTab").click(function(){ $("#tabs4").tabs("option", "active", 2); });

📌 Important Tabs Options (Exam Friendly)

  • active → Set default open tab
  • collapsible → Allow closing tabs
  • disabled → Disable specific tabs

📌 Common Tabs Methods

  • .tabs("option", "active", index)
  • .tabs("disable", index)
  • .tabs("enable", index)
