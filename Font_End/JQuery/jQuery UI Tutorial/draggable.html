jQuery UI Draggable

The Draggable widget allows elements to be moved using the mouse. It supports axis control, containment, and drag events.

1️⃣ Basic Draggable

This is the default draggable behavior with no restrictions.

$("#drag1").draggable();
Drag Me

2️⃣ Axis Restriction

Using axis, movement can be restricted to X or Y direction.

$("#drag2").draggable({ axis: "x" });
X Axis

3️⃣ Containment

containment restricts dragging within a parent element.

$("#drag3").draggable({ containment: "parent" });
Inside Box

4️⃣ Draggable Events

Draggable supports start, drag, and stop events.

$("#drag4").draggable({ start: function () { $("#status").text("Dragging started"); }, drag: function () { $("#status").text("Dragging..."); }, stop: function () { $("#status").text("Dragging stopped"); } });
Drag Events

Status: Not dragging

📌 Important Draggable Options (Exam Friendly)

  • axis → Restrict movement direction
  • containment → Limit draggable area
  • cursor → Change cursor style
  • grid → Move element in grid steps

📌 Draggable Events

  • start → Fired when dragging begins
  • drag → Fired while dragging
  • stop → Fired when dragging ends
