jQuery UI Slider

The Slider widget allows users to select a value or range by dragging a handle along a track.

1️⃣ Basic Slider with Value Display

This is a simple slider that displays the current value in real time.

$("#slider1").slider({ slide: function(event, ui) { $("#val1").text(ui.value); } });
Value: 0

2️⃣ Slider with Step Control

The step option allows movement in fixed increments.

$("#slider2").slider({ min: 0, max: 100, step: 10 });

3️⃣ Slider with Default Value

You can set a default starting value using value.

$("#slider3").slider({ value: 50 });
Default Value: 50

4️⃣ Range Slider (Min & Max Selection)

A range slider allows users to select a value range instead of a single value.

$("#slider4").slider({ range: true, min: 0, max: 500, values: [100, 300], slide: function(event, ui) { $("#range").text(ui.values[0] + " - " + ui.values[1]); } });
Selected Range: 100 - 300

📌 Important Slider Options (Exam Friendly)

  • min → Minimum value
  • max → Maximum value
  • value → Default slider value
  • step → Step interval
  • range → Enable range selection

📌 Slider Events

  • slide → Fires during sliding
  • change → Fires when value changes
