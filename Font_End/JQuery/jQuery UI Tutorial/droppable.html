jQuery UI Droppable

The Droppable widget allows elements to be dropped onto a target. It is commonly used with Draggable for drag-and-drop functionality.

1️⃣ Basic Droppable

Any draggable element can be dropped into the target.

$("#drag1").draggable(); $("#drop1").droppable({ drop: function () { $(this).text("Dropped!"); } });

2️⃣ Accept Specific Elements

Using accept, only selected elements are allowed to be dropped.

$("#drop2").droppable({ accept: ".allowed" });

3️⃣ Hover Effect

hoverClass adds a CSS class when a draggable is over the target.

$("#drop3").droppable({ hoverClass: "hovered" });

4️⃣ Drop Event with Action

The drop event executes custom logic when an element is dropped.

$("#drop4").droppable({ drop: function (event, ui) { $(this).text("Dropped: " + ui.draggable.text()); } });

📌 Important Droppable Options (Exam Friendly)

  • accept → Specify allowed draggable elements
  • hoverClass → Apply CSS on hover
  • tolerance → Define drop sensitivity

📌 Droppable Events

  • drop → Fired when draggable is dropped
  • over → Fired when draggable enters
  • out → Fired when draggable leaves
