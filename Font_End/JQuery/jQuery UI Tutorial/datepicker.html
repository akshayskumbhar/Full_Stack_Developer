jQuery UI Datepicker

The Datepicker widget provides a popup calendar that allows users to select a date easily instead of typing it manually.

1️⃣ Basic Datepicker

This is the default Datepicker with no options. Click inside the input field to open the calendar.

$("#date1").datepicker();

2️⃣ Date Format Customization

Using dateFormat, we can control how the selected date is displayed.

$("#date2").datepicker({ dateFormat: "dd-mm-yy" });

3️⃣ Disable Past Dates

minDate: 0 disables all past dates. This is commonly used in booking forms.

$("#date3").datepicker({ minDate: 0 });

4️⃣ Month & Year Dropdown + Range

This example allows users to change month and year, and restricts date selection within a range.

$("#date4").datepicker({ changeMonth: true, changeYear: true, minDate: "-1y", maxDate: "+1y" });

📌 Important Datepicker Options (Exam Friendly)

  • dateFormat → Controls date display format
  • minDate → Disable previous dates
  • maxDate → Restrict future dates
  • changeMonth → Month dropdown
  • changeYear → Year dropdown
