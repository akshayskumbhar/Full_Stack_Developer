jQuery UI Dialog

The Dialog widget is used to display content in a popup window. It can be modal or non-modal and supports custom buttons and events.

1️⃣ Basic Dialog (Auto Open)

This dialog opens automatically when the page loads.

$("#dialog1").dialog();
This is a simple dialog box.

2️⃣ Modal Dialog

A modal dialog disables the background until the dialog is closed.

$("#dialog2").dialog({ modal: true });
You must close this dialog to interact with the page.

3️⃣ Dialog with Custom Buttons

Dialogs can contain multiple custom buttons with actions.

$("#dialog3").dialog({ buttons: { Ok: function () { alert("You clicked OK"); $(this).dialog("close"); }, Cancel: function () { $(this).dialog("close"); } } });
Are you sure you want to continue?

4️⃣ Open & Close Dialog Programmatically

Dialogs can be opened and closed using buttons and methods.

$("#dialog4").dialog({ autoOpen: false }); $("#openBtn").click(function(){ $("#dialog4").dialog("open"); });
This dialog is opened and closed using buttons.

📌 Important Dialog Options (Exam Friendly)

  • modal → Disable background
  • autoOpen → Open on page load
  • buttons → Add custom buttons
  • width / height → Dialog size

📌 Common Dialog Methods

  • .dialog("open")
  • .dialog("close")
  • .dialog("destroy")
