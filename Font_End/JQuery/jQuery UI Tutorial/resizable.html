jQuery UI Resizable

The Resizable widget allows users to resize elements using the mouse. It supports resize handles, size restrictions, and events.

1️⃣ Basic Resizable

This is the default resizable behavior. Resize the box using corner handles.

$("#resize1").resizable();
Resize Me

2️⃣ Custom Resize Handles

Using handles, you can control which sides are resizable.

$("#resize2").resizable({ handles: "e, s, se" });
East & South

3️⃣ Min & Max Size

minWidth, maxWidth, minHeight, and maxHeight control resize limits.

$("#resize3").resizable({ minWidth: 120, maxWidth: 300, minHeight: 120, maxHeight: 300 });
Size Limits

4️⃣ Maintain Aspect Ratio + Events

aspectRatio: true keeps width and height proportional. Resize events track resizing actions.

$("#resize4").resizable({ aspectRatio: true, start: function () { $("#status").text("Resizing started"); }, resize: function () { $("#status").text("Resizing..."); }, stop: function () { $("#status").text("Resizing stopped"); } });
Aspect Ratio

Status: Not resizing

📌 Important Resizable Options (Exam Friendly)

  • handles → Control resize direction
  • minWidth / minHeight → Minimum size
  • maxWidth / maxHeight → Maximum size
  • aspectRatio → Maintain ratio

📌 Resizable Events

  • start → Resize starts
  • resize → During resize
  • stop → Resize ends
