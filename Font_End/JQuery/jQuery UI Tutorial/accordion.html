jQuery UI Accordion

The Accordion widget is used to display content in collapsible panels. Only one section is open at a time.

1️⃣ Basic Accordion

This is the default accordion with no options.

$("#accordion1").accordion();

HTML is used to structure web pages.

CSS

JavaScript

JavaScript adds behavior.

2️⃣ Collapsible Accordion

Using collapsible: true, all panels can be closed.

$("#accordion2").accordion({ collapsible: true, active: false });

3️⃣ Height Style = Content

heightStyle: "content" adjusts height based on content.

$("#accordion3").accordion({ heightStyle: "content" });

4️⃣ Accordion Events

The activate event fires when panel changes.

$("#accordion4").accordion({ activate: function () { alert("Panel Changed"); } });

Summary

  • active → controls open panel
