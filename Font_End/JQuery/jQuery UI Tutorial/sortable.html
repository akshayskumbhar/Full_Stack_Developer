jQuery UI Sortable

The Sortable widget allows users to reorder list items using drag and drop. It supports axis control, events, and connected lists.

1️⃣ Basic Vertical Sortable

This is the default sortable list. Items can be reordered vertically.

$("#list1").sortable();

2️⃣ Axis Restricted Sorting

Using axis: "y", items can only be moved vertically.

$("#list2").sortable({ axis: "y" });

3️⃣ Update Event

The update event fires when the order of items changes. This is useful for saving order to a database.

$("#list3").sortable({ update: function () { $("#order").text($(this).sortable("toArray").join(", ")); } });

4️⃣ Connected Sortable Lists

Items can be moved between multiple sortable lists.

$(".connected").sortable({ connectWith: ".connected" });

📌 Important Sortable Options (Exam Friendly)

  • axis → Restrict movement direction
  • placeholder → Visual placeholder
  • connectWith → Connect multiple lists

📌 Sortable Events

  • update → Order changed
  • start → Drag start
  • stop → Drag stop
