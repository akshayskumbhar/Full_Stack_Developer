jQuery UI Selectable

The Selectable widget allows users to select one or more elements by dragging the mouse over them. It is commonly used in lists and grids.

1️⃣ Basic Selectable

Click or drag to select multiple list items.

$("#select1").selectable();

2️⃣ Selecting Multiple Items

You can select multiple items by dragging across them.

3️⃣ Filter Option

The filter option allows selection of specific elements only.

$("#select3").selectable({ filter: "li" });

4️⃣ Select & Unselect Events

Selectable supports selected and unselected events.

$("#select4").selectable({ selected: function () { $("#status").text("Item selected"); }, unselected: function () { $("#status").text("Item unselected"); } });

📌 Important Selectable Options (Exam Friendly)

  • filter → Restrict selectable elements
  • cancel → Prevent selection on specific elements
  • distance → Minimum drag distance

📌 Selectable Events

  • start → Selection starts
  • selected → Item selected
  • unselected → Item unselected
  • stop → Selection stops
