Introduction to Bootstrap and Basic Setup

📌 Definition & Importance

🧾 What is Bootstrap?

work used to develop responsive and mobile-first websites It includes HTML, CSS, and JavaScript-based design templates for typography, forms, buttons, navigation, and other interface components

🎯 Why is it important?

  • Speeds up development with pre-designed components
  • Ensures mobile-first responsiveness
  • Cross-browser compatible and consistent UI/UX
  • Simplifies layout management using the grid system

🔍 Detailed Explanation of Subtopics

1] What is Bootstrap?

  • Developed by Twitter engineers (Mark Otto and Jacob Thornton)
  • Current version: Bootstrap 5 (no jQuery dependency).
  • Great for rapid prototyping and responsive layouts

2] Advantages of Using Bootstrap

  • Built-in responsive grid
  • Pre-styled components (modals, buttons, navbars).
  • Sass customization support.
  • Large community and extensive documentation.

3] Bootstrap vs. Custom CSS
